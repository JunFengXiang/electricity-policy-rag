# 数据采集说明

当前知识库采用“种子链接采集”的方式起步。也就是先人工确认一批可靠链接，再由脚本下载原文并登记台账。

同时，后续所有自动采集都应以 `02_元数据/来源清单.csv` 为白名单来源，不再做无边界的全站乱爬。

目前已经形成两条采集链路：

```text
链路一：种子链接采集
待采集链接.csv -> 01_fetch_seed_urls.py -> 原始文件/纯文本/台账

链路二：来源白名单候选采集
来源清单.csv -> 02_collect_official_candidates.py -> 候选链接清单
```

## 为什么先用种子链接

- 官方网站栏目结构经常变化，直接全站爬取容易抓到大量无关内容。
- 政策知识库更看重来源可靠和有效性，人工筛选第一批种子链接更稳。
- 后续资料量变大后，再按具体网站开发栏目采集器。

## 怎么采集

前置动作：

1. 先确认目标来源已经在 `02_元数据/来源清单.csv` 中。
2. 只从该来源的 `优先入口URL` 和定义好的 `抓取边界` 开始。
3. 如果来源还没有入清单，先补来源，不直接开爬。

正式步骤：

1. 在 `02_元数据/待采集链接.csv` 中新增链接。
2. 填写来源名称、来源类型、发布部门、适用地区、市场主题、关键词等字段。
3. 在项目根目录运行：

```powershell
D:\miniconda\envs\py311\python.exe .\scripts\01_fetch_seed_urls.py
```

如果先想从白名单来源自动找候选链接，运行：

```powershell
C:\Users\102\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe .\scripts\02_collect_official_candidates.py
```

这个脚本会：

```text
1. 读取 02_元数据/来源清单.csv
2. 只扫描 状态=启用 且 是否纳入自动采集=是 的来源
3. 当前支持 HTML列表、JSON列表、部分公开平台页面
4. 输出候选链接到 05_输出成果
```

## 测试采集

只抓一条：

```powershell
D:\miniconda\envs\py311\python.exe .\scripts\01_fetch_seed_urls.py --limit 1
```

只测试能否访问，不写入文件：

```powershell
D:\miniconda\envs\py311\python.exe .\scripts\01_fetch_seed_urls.py --dry-run --limit 1
```

## 采集结果

脚本会做三件事：

```text
1. 保存网页或文件到 01_原始资料
2. 如果是网页，提取纯文本到 03_处理后文本
3. 往 02_元数据/政策资料台账.csv 追加一条记录
4. 往 06_实验日志/操作日志.csv 和 实验日志.md 追加一条运行日志
```

## 注意事项

- 先抓官方政策和交易规则，再抓解读资料。
- 不建议直接批量爬公众号页面，优先用授权、导出或人工整理方式入库。
- 每次采集后都要人工复核标题、发布日期、有效状态和适用地区。
- 对政府网站保持低频访问，默认每条链接间隔 2 秒。
