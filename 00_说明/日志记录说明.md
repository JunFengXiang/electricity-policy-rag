# 日志记录说明

知识库建设过程中的重要操作都应记录到 `06_实验日志`。

## 日志文件

```text
06_实验日志/实验日志.md
  人工阅读版本，适合复盘每一步做了什么。

06_实验日志/操作日志.csv
  结构化版本，适合用 Excel 筛选和统计。
```

## 手动追加日志

在知识库根目录运行：

```powershell
D:\miniconda\envs\py311\python.exe .\scripts\log_action.py --type "操作类型" --content "做了什么" --files "涉及文件" --command "运行命令" --result "结果" --note "备注"
```

示例：

```powershell
D:\miniconda\envs\py311\python.exe .\scripts\log_action.py --type "人工复核" --content "复核第一批官方政策标题和发布日期" --files "02_元数据/政策资料台账.csv" --result "完成" --note "3条资料均确认来源可靠"
```

## 自动记录

`scripts/01_fetch_seed_urls.py` 已接入日志。每次运行采集脚本后，会自动追加一条记录，包含：

- 运行命令
- 成功采集数量
- 失败数量
- 是否为 dry-run 测试
- 涉及文件和目录

## 建议记录的操作

- 新增或调整目录结构
- 新增或修改台账字段
- 新增来源链接
- 运行采集脚本
- 人工复核资料
- 修改标签体系和权重规则
- 生成专题报告或检索结果
