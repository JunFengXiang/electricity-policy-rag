# 第一周建设清单

第一周的目标不是做系统，而是把资料管理口径跑通。建议用 5 个小动作完成第一版知识库雏形。

## 第 1 步：确定试点范围

建议先选：

```text
国家级政策
+ 1 到 3 个重点省份
+ 中长期、现货、辅助服务三个主题
```

不要一开始覆盖所有省份，否则整理压力会很大。

## 第 2 步：收集第一批资料

优先收这几类：

| 优先级 | 资料类型 | 建议数量 |
|---|---|---|
| P0 | 国家级电力市场基础政策 | 10-20份 |
| P0 | 重点省份现货/中长期/辅助服务规则 | 20-40份 |
| P1 | 电力交易中心实施细则、结算规则、注册规则 | 20-40份 |
| P1 | 官方解读、答疑、市场运行报告 | 10-20份 |
| P2 | 公众号、咨询机构解读文章 | 20-50份 |

## 第 3 步：文件放到对应目录

```text
官方政策 -> 01_原始资料/官方政策
交易规则 -> 01_原始资料/交易规则
公众号解读 -> 01_原始资料/解读资料
咨询报告 -> 01_原始资料/咨询报告
```

文件名建议统一成：

```text
发布日期_地区_发布部门_文件标题
```

示例：

```text
2024-01-15_广东_广东电力交易中心_电力现货市场交易实施细则.pdf
```

## 第 4 步：登记资料台账

每份资料至少填写：

```text
文件标题
发布部门
发布日期
适用地区
来源类型
市场主题
关键词
权威等级
时间敏感类型
有效状态
原文链接
本地文件路径
```

## 第 5 步：做一次人工复核

重点检查：

- 是否是官方原文，还是转载版本。
- 是否为征求意见稿、试行稿、正式稿。
- 是否已经被新文件替代。
- 文件适用地区是否明确。
- 公众号和咨询解读是否能对应到官方文件。

## 第一周完成标准

完成后，知识库至少应该能回答：

```text
我现在有哪些国家级电力市场政策？
某个省有哪些现货市场规则？
辅助服务相关文件有哪些？
哪些资料是官方原文，哪些只是解读？
最近 15 天或 30 天新增了哪些资料？
```
