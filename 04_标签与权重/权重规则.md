# 权重规则

搜索结果排序不要只按发布时间，也不要只按关键词。电力政策资料应采用综合排序。

## 1. 综合排序因素

```text
综合排序 =
内容相关性
+ 来源权威性
+ 有效状态
+ 地区匹配度
+ 主题匹配度
+ 分类型时间权重
```

## 2. 权威等级

| 等级 | 类型 | 排序口径 |
|---|---|---|
| A | 国家级/省级官方政策原文 | 回答主要依据，优先展示 |
| B | 监管机构、交易中心规则和实施细则 | 业务执行依据，优先展示 |
| C | 官方解读、答疑、新闻发布 | 辅助解释，靠前展示 |
| D | 公众号、咨询机构、行业报告 | 参考资料，不替代官方依据 |
| E | 转载、个人文章、来源不明材料 | 低优先级，谨慎使用 |

## 3. 分类型时间权重

不同资料类型采用不同时间衰减速度。

### 长期有效型

适用资料：官方政策原文、正式规则、实施细则、监管办法。

| 时间范围 | 时效判断 |
|---|---|
| 0-90天 | 新文件 |
| 91-180天 | 较新 |
| 181-365天 | 正常 |
| 1-3年 | 历史有效 |
| 3年以上 | 老文件，重点看是否仍有效 |

排序原则：权威性和有效状态优先，时间只做辅助。

### 中期参考型

适用资料：官方解读、交易通知、地方工作安排、市场运行月报、征求意见稿。

| 时间范围 | 时效判断 |
|---|---|
| 0-15天 | 很新 |
| 16-30天 | 新 |
| 31-60天 | 较新 |
| 61-90天 | 正常 |
| 90天以上 | 逐渐降权 |

排序原则：兼顾发布时间、适用地区和主题相关性。

### 短期资讯型

适用资料：公众号文章、咨询快评、行业新闻、会议动态、市场快讯。

| 时间范围 | 时效判断 |
|---|---|
| 0-2天 | 最新 |
| 3-4天 | 很新 |
| 5-7天 | 新 |
| 8-14天 | 较新 |
| 15-30天 | 正常 |
| 30天以上 | 明显降权 |

排序原则：新鲜度较重要，但权威性不高，不能压过官方原文。

## 4. 默认排序策略

默认搜索结果应按以下顺序倾向展示：

1. 主题和地区高度匹配的现行官方文件。
2. 相关交易规则、实施细则、监管要求。
3. 近期官方通知、官方解读、答疑材料。
4. 近期公众号、咨询机构、行业报告。
5. 历史版本、征求意见稿、状态未知资料。

## 5. 特别规则

- 已废止文件默认不参与主排序，只在“历史版本”或“政策沿革”场景展示。
- 征求意见稿要明确标注，不能当作正式政策引用。
- 公众号和咨询资料可以靠新鲜度提前展示，但回答结论应优先回到官方原文。
- 旧文件如果仍然现行有效，应保留较高展示优先级。
- 高质量发展、电网、新型电力系统、电力保供等战略主题可以提高召回优先级，但不改变来源权威等级。
- 官方解读默认 C 级，只能辅助解释；公众号、咨询机构、行业媒体默认 D 级，未人工关联官方文件前不进入主问答索引。
