# 标签体系

标签用于让资料能按地区、部门、市场类型、业务环节和权威程度检索。第一阶段先保持简洁，后续根据资料增长再细化。

## 1. 来源类型

| 标签 | 说明 |
|---|---|
| 官方政策 | 国家或地方主管部门正式发布的政策、通知、办法 |
| 交易规则 | 电力交易中心、市场运营机构发布的规则、细则、指南 |
| 官方解读 | 主管部门、交易机构发布的政策解读、答记者问 |
| 公众号解读 | 公众号、行业媒体、个人或机构解读 |
| 咨询报告 | 咨询机构、研究机构整理的专题报告 |
| 新闻快讯 | 新闻稿、会议动态、市场快讯 |

## 2. 政策层级

| 标签 | 说明 |
|---|---|
| 国家级 | 国家发改委、国家能源局、工信部等国家部委 |
| 区域监管 | 华北、东北、西北、华东、华中、南方等监管机构 |
| 省级 | 省发改委、省能源局、省工信厅等 |
| 交易机构 | 电力交易中心、市场运营机构 |
| 第三方 | 公众号、咨询机构、行业媒体 |

## 3. 市场主题

| 标签 | 说明 |
|---|---|
| 电力市场 | 综合性电力市场建设政策 |
| 中长期 | 年度、月度、月内、多日等中长期交易 |
| 现货 | 日前、实时、出清、价格机制、结算等 |
| 辅助服务 | 调频、备用、爬坡、无功、黑启动、费用分摊等 |
| 省内交易 | 省内市场交易与结算规则 |
| 省间交易 | 省间中长期、省间现货、跨区跨省交易 |
| 绿电绿证 | 绿色电力交易、绿证、可再生能源消纳 |
| 容量机制 | 容量电价、容量补偿、可靠性机制 |
| 需求响应 | 需求侧响应、虚拟电厂、负荷聚合 |
| 储能 | 新型储能参与市场、独立储能、共享储能 |

## 4. 业务环节

| 标签 | 说明 |
|---|---|
| 市场准入 | 注册、准入条件、主体资格 |
| 交易组织 | 交易周期、交易品种、申报方式 |
| 出清机制 | 出清模型、价格形成、节点/分区价格 |
| 合同管理 | 合同签订、分解、转让、调整 |
| 偏差考核 | 偏差电量、偏差费用、考核机制 |
| 结算规则 | 结算周期、结算公式、费用分摊 |
| 信息披露 | 披露内容、披露频率、披露主体 |
| 风险管理 | 履约保函、信用评价、市场风险控制 |

## 5. 有效状态

| 标签 | 说明 |
|---|---|
| 现行有效 | 当前可作为正式依据 |
| 试行 | 试点或暂行文件 |
| 征求意见 | 尚未正式生效 |
| 已废止 | 已明确废止 |
| 被替代 | 被后续文件替代 |
| 状态未知 | 暂未确认，需要复核 |
